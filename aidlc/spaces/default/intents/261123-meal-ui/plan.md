# P1c 献立の手動記録・閲覧画面の実装計画

P1a のデータ基盤と P1b の API は main に取り込み済み。P1c で、家族が同じワークスペースで献立を記録・編集し、過去の料理を再利用できるようにする。

- AC-01 閲覧・検索。スマホと PC の週・月表示から日付を選び、朝・昼・夕の記録と詳細を確認できる。料理名検索では同じ料理を作った日ごとに結果を表示する。
- AC-02 登録・編集・削除。日付・食事区分・料理名だけで登録できる。複数の料理、人数、食材、分量、レシピ本文または URL を後から編集できる。
- AC-03 コピー。献立全体は空き枠へコピーできる。料理単体は空き枠や既存の献立に追加できる。人数と分量を保存前に確認し、コピー元の記録を保持する。
- AC-04 共有と競合。同じ共有ワークスペースの家族が確認・編集できる。通信失敗や更新競合でも入力を保持し、最新版を確認できる。同じ送信の再試行で二重登録を防ぐ。

既存の献立 API を使い、料理単体のコピーはコピー先の編集画面で確認してから保存する。画面は設計書のミルフィーユ配色に沿って実装する。最終コミットで独立レビュー、テスト、ビルド、架空 A/B によるスマホ・PC のブラウザ QA、GitHub CI と正式 PR Preview を確認する。
