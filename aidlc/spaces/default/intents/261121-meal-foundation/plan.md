# P1a 献立のデータ基盤を実装する計画

技術詳細設計のP1aとして、家族の共有ワークスペースで献立・料理・食材を安全に保存し、取得できる基盤を作る。

1. 最新の main から開発ブランチを作り、003_meals.sql と生成済み初期化SQLを追加・更新する。既存の移行原本、環境識別、ハッシュ照合と移行ランナーを継承する。
2. Meal DTO、Zod、Repositoryを実装する。現在の利用可否とワークスペース所属をDB内で照合し、親子の保存・削除を一括で確定する。食事枠の一意性、期待版、料理と食材の所属を確認する。
3. 空DB、002からの増分移行、入力の境界値、権限、競合、途中失敗時のロールバックをPGliteで確認する。最終コミットを別Agentがレビューし、lint・型検査・テスト・build・ローカルQAを実行する。
4. draft PRの同じSHAのCIと正式Preview、PC・スマホの架空A/B、専用Preview DBの独立接続からの主要な競合を確認して結果を記録する。

HTTP API・コピー・料理名検索・HTTP再送契約はP1b、献立画面はP1cで扱う。
