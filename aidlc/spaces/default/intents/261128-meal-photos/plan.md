# P3 写真による入力支援の実装計画

P2の献立提案・予定保存・実績化と専用PreviewのOpenAI実モデル検証までが完了した。P3では次の順序で既存の献立編集・詳細・検索を拡張する。

1. 献立編集でJPEG・PNG・WebPを添付できるようにする。初期上限は1枚8 MiB・20メガピクセルとし、位置情報などのメタデータを除去する。閲覧時はワークスペースへの所属を確認し、添付解除・削除後の画像を回収する。
2. 写真から推定した料理・食材・分量を候補として表示する。材料の追加・削除と分量・単位の修正、不明な量の空欄保存に対応する。解析失敗時も写真を添付したまま手入力を続けられ、解析中の入力は保持する。
3. 既存の検索画面に食材名検索を追加し、その食材を使った記録済みの料理を日付ごとに探せるようにする。

Previewの分離、画像の保持条件、費用を確認して保存先とモデルを選定する。所属外からの閲覧拒否、画像の回収、解析失敗時の入力保持をテストし、スマホ・PCと正式PR Previewで確認する。
