# P2 献立提案の実LLM接続計画

- 既存の提案アダプターに Vercel AI Gateway を追加する。第一候補は構造化出力と日本での推論に対応する GPT-6 Luna。日本に固定できるのは推論で、Gateway の受信は別の地域になる場合がある。
- 初回は専用 PR Preview で架空データを使う。送信項目は献立条件、最近の料理名、追加要望など提案に必要な情報に絞り、保持なしの経路を指定する。実モデル試験は最大10回。1回あたり入出力各2,000トークンなら、日本リージョンの公開単価で約0.013米ドル。
- 日本語の献立案が条件と追加要望を反映し、既存の予定保存・実績化につながることを確認する。不正な応答やタイムアウト時の候補保持、同じ送信の再試行で二重に生成されないことも検証する。
