# P2 献立提案のOpenAI API直接接続計画

- 既存のサーバー側アダプターをOpenAI Chat Completions APIへ直接接続する。第一候補はGPT-6 Luna（`gpt-6-luna`）。標準のグローバル接続を使い、対象APIプロジェクトでZDRを確認し、`store: false` を指定する。
- 専用PR Previewに明示的に設定した架空データで、実モデルの試験を最大10回行う。対象のOpenAI APIプロジェクト・クレジットと、専用デプロイの実行時だけに資格情報を渡す経路を照合する。Cloud・CIはサンプル応答を使う。
- 既存の認証、所属確認、入出力上限、構造化出力検証、失敗時の保持と再送時の非重複を確認する。日本語の提案から追加要望、予定採用、実績化までを確認し、モデル、リクエストID、応答時間、トークン数、費用を記録する。
