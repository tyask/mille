# mille 設計文書

献立機能の要件と設計を管理する。文書とモックは実装前の設計案であり、機能の実装状況は[プロジェクトREADME](../../README.md)を参照する。

| 文書 | 内容 |
| --- | --- |
| [要件書](../requirements.md) | 利用形態、P1〜P4の機能要件、実装後に確認する受入条件 |
| [画面設計書](screen-design.md) | スマホ・PCの構成、ミルフィーユ配色、画面モック |
| [技術詳細設計書](technical-design.md) | DB・API・権限・競合・再送、後続機能、移行と検証 |

## 文書の位置づけ

- 既存実装はGoogle認証と個人・共有ワークスペース。献立関連の機能はP1から段階的に追加する計画である。
- 画面設計はv0.2、技術詳細設計はv0.1を基準に、2026年11月19日にGit管理用へ整理した。
- 画面画像は架空の利用者・献立を使った仕様検討用の静的モックで、操作ボタンの表示はアプリの動作を保証しない。
- 件数・容量・期限・応答時間の上限や未選定の外部サービスは設計提案として扱う。
- 文書間と画像のリンクはリポジトリ内で完結する。配布用PDF、ZIP、過去版、一時検証ログ、操作サンプルの実装コードは正本に含めない。

## 設計の更新

要件を変える場合は、要件書の段階と受入条件、画面設計、技術詳細設計を対応付けて更新する。アプリの実装完了は、該当する実装PRと検証結果を確認してから要件書のチェックへ反映する。

既存の共有・認証仕様は[ワークスペース仕様](../workspaces.md)、開発・承認・検証の手順は[開発手順](../development.md)を参照する。
